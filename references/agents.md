# Agents d'Nature Odds (delta sur `$AH/references/agents.md`)

Le brief générique de chaque rôle est dans `$AH/references/agents.md` (lire la seule section du rôle : `grep -n '^###' $AH/references/agents.md`). Ce fichier dit **ce qui change** ; il prime. Chaque agent écrit son livrable dans un fichier du dossier de travail et ne rend que ≤ 10 lignes : verdict, chemin, points bloquants. Référence de forme : `identity.md` ; `reference-depth-theory.md` ne sert qu'aux principes, jamais à la forme.

| Rôle | Agent (`subagent_type`, modèle) | Ce qui change pour Nature Odds |
|---|---|---|
| Story architect | `story-architect`, sonnet | 3 parties possibles, chacune = format (A/B/C/D, différent de l'épisode précédent) + titre au gabarit `identity.md` §2 + lieu et but + 5 niveaux (une capacité sourcée par niveau) + 5 choix A/B/C avec la bonne réponse et sa source + retournement + fin (GAME OVER ou YOU SURVIVED) + **mécanique neuve** du HUD. Écarter tout animal ou format déjà publié par l'utilisateur. |
| Fact-checker | `fact-checker`, sonnet | Chaque record avec la fourchette de l'étude ; chaque rencontre réelle datée et sourcée ; chaque bonne réponse de choix appuyée par une source ; le debrief de sécurité tiré d'une source officielle (NOAA, gardes-côtes, Croix-Rouge). |
| Script writer | `general-purpose`, sonnet | Structure `identity.md` §3, écriture §4, voix de l'ordinateur de survie §1 ; écrit aussi `hud.json` (une clé par niveau et par choix tranché : o2, odds, depth, level ; événements GAME OVER / YOU SURVIVED / CHOICE LOCKED aux temps des phrases). |
| Script critic | `general-purpose`, haiku | Vérifie : HUD et but avant 0:25 ; 5 niveaux ; un choix A/B/C par niveau tranché par un fait ; retournement vers 55 % ; score de jeu dit comme tel ; debrief ≤ 60 s ; aucun gore ; outro ≤ 3 phrases. |
| **Originality checker** (nouveau) | `general-purpose`, haiku | Lance `$DT/scripts/originality.py` deux fois (`--ref` sur les transcriptions de la chaîne étudiée, puis `--ref published`, `identity.md` §3 bis) sur le script, le titre et la description ; vérifie `brief.json.new_mechanic` et que le format diffère de l'épisode précédent. Verdict OK ou la liste des hits à réécrire. Bloquant. |
| Render router / Visual director | `visual-director`, haiku | Familles : scènes néon 50 %, cartes `html` 30 % (choix, niveaux, records à l'échelle humaine), vue subjective du joueur 10 % (`pov_hands`), photos/archives réelles légendées « REAL FOOTAGE » 10 % ; aucune image Flow avec du texte ou un HUD. |
| Image director | `general-purpose`, sonnet | Style `nature-neon` ; l'explorateur orange toujours minuscule, tenue adaptée au milieu ; anatomie juste de l'espèce ; une image de révélation par créature (lumière qui s'allume sur l'animal). |
| Image QC | `image-qc`, haiku | Phrase de contrôle = champ `qc` du style `nature-neon` + « anatomie conforme à l'espèce nommée ». |
| Audio director | `general-purpose`, haiku | Voix calme et sèche d'ordinateur de survie (Brian ou Daniel, stabilité haute), 160 à 172 mots/min ; son `identity.md` §6 : lit de détendeur, bips, sonar, alarme, ~8 effets/min, pas de musique dramatique. |
| Motion designer | `general-purpose`, sonnet | `$DT/scripts/hud.py <projet> hud.json` après `hf_build.py` ; cartes-choix et cartes-niveaux aux couleurs et polices `identity.md` §5 ; `npx hyperframes check` ok puis `snapshot` lu. Sous-titres : non par défaut (le HUD occupe l'écran), oui si l'utilisateur les veut (en bas, sans cacher les cartes). |
| Packaging strategist | `packaging-strategist`, sonnet | Titre au gabarit `identity.md` §2 du format de l'épisode ; texte de miniature au gabarit §5, lint par `$DT/scripts/thumb_odds.py`. |
| SEO / description | `seo-metadata-editor`, sonnet | Gabarit `identity.md` §7 (mention « score de jeu », mention IA, sources, 3 hashtags, tags ≤ 500 caractères). |
| Publication checker | `general-purpose`, haiku | Passe `references/youtube-compliance.md` case par case ; une case non cochée bloque. |
| Sensitivity checker | `general-purpose`, haiku, seulement format D | Rencontre réelle avec victime : aucun détail gore, nom seulement s'il est public, ton respectueux, pas de score de jeu sur une mort réelle (le format D se termine sur « what really happened », sans GAME OVER). |
| Community manager | `general-purpose`, haiku | Posts `$AH/references/publication-seo.md` §8, recentrés sur le jeu (sondage « A, B or C? » la veille, résultat le lendemain) ; images carrées par `$DT/scripts/thumb_odds.py --force`. |
